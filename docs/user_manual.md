# คู่มือการใช้งานระบบ SentinelAI (Installation Guide & User Manual)

**SentinelAI** เป็นแพลตฟอร์ม AI สำหรับช่วยวิเคราะห์และจัดลำดับความสำคัญของการแจ้งเตือนภัยคุกคามทางไซเบอร์ (**Security Alerts**) โดยผู้ใช้งานสามารถนำเข้าไฟล์แจ้งเตือนจาก **Wazuh** ให้ระบบประเมินความเสี่ยง วิเคราะห์เหตุการณ์ และแสดงผลเพื่อช่วยให้ผู้ดูแลระบบตัดสินใจตรวจสอบได้ง่ายขึ้น โดย**ไม่ต้องเข้าสู่ระบบ (No Login) หรือสมัครสมาชิก (No Register)** และจัดเก็บข้อมูลเฉพาะในช่วงการใช้งานปัจจุบัน (**Temporary Session**)

---

## 1. ภาพรวมขั้นตอนการใช้งาน 6 ขั้นตอน

### ขั้นตอนที่ 1: นำเข้าข้อมูล (Upload Alerts)
ผู้ใช้งานเลือกอัปโหลดไฟล์ **JSON** หรือ **CSV** ที่ส่งออกมาจาก Wazuh หรือกรอกข้อมูล Alert ด้วยตนเองในหน้า **`Dashboard & Upload`** จากนั้นระบบจะตรวจสอบรูปแบบและความถูกต้องของข้อมูล (Schema Validation & Deduplication)

### ขั้นตอนที่ 2: เลือก Alert ที่ต้องการวิเคราะห์ (Select Alert)
ระบบแสดงรายการ Alert ทั้งหมดใน Session ปัจจุบันเพื่อให้ผู้ใช้งานเลือกเหตุการณ์ที่ต้องการตรวจสอบ เช่น ประเภทเหตุการณ์ ระดับความรุนแรงเบื้องต้น IP Address และเวลาเกิดเหตุ
- กรณีอัปโหลดไฟล์ CSV ที่มีหลายรายการ (เช่น 100 Alerts) ผู้ใช้งานสามารถเลือกวิเคราะห์ทีละรายการ และสลับไปเลือก Alert อื่นจากไฟล์เดียวกันได้ทันทีโดยไม่ต้องอัปโหลดไฟล์ใหม่

### ขั้นตอนที่ 3: วิเคราะห์และประเมินความเสี่ยง (AI Analysis)
เมื่อผู้ใช้งานเลือก Alert และกดปุ่ม **Analyze** ในหน้า **`Analysis Workspace`** ระบบจะประมวลผลข้อมูลตามลำดับ ดังนี้:
- **Data Normalization**: จัดรูปแบบข้อมูลให้อยู่ในโครงสร้างมาตรฐานเดียวกัน
- **Risk Scoring**: คำนวณคะแนนความเสี่ยง (`0–100`) จากความรุนแรงและพฤติกรรมที่ตรวจพบ
- **AI Analysis**: สรุปเหตุการณ์และอธิบายสาเหตุที่ควรตรวจสอบพร้อมอ้างอิงหลักฐาน
- **MITRE ATT&CK Mapping**: เชื่อมโยงเหตุการณ์กับเทคนิคการโจมตีในกรอบ MITRE ATT&CK
- **Prioritization**: จัดลำดับความสำคัญของเหตุการณ์ (`Critical`, `High`, `Medium`, `Low`)

### ขั้นตอนที่ 4: ตรวจสอบและยืนยันผล (Analyst Review)
ผู้ใช้งานตรวจสอบผลลัพธ์ที่ได้จาก AI ในหน้า **`Analyst Review & Audit`** โดยสามารถ:
- พิมพ์ชื่อผู้ตรวจสอบ / ผู้อนุมัติ
- เพิ่มหมายเหตุความคิดเห็นของนักวิเคราะห์
- ปรับระดับการประเมินความเสี่ยง (`Severity` และ `Risk Score`) หรือกดยืนยันผลการวิเคราะห์
- ขั้นตอนนี้ช่วยให้ AI ทำหน้าที่เป็นเครื่องมือช่วยวิเคราะห์ (**Decision-Support Tool**) แต่การตัดสินใจสุดท้ายยังเป็นของผู้ใช้งาน (**Human-in-the-Loop**)

### ขั้นตอนที่ 5: สร้างรายงาน (Generate Report)
เมื่อยืนยันผลการวิเคราะห์แล้ว ผู้ใช้งานสามารถเปิดหน้า **`Report`** เพื่อสร้างและดาวน์โหลดรายงานในรูปแบบ **PDF** หรือ **CSV** ซึ่งประกอบด้วย:
- ข้อมูล Alert ต้นฉบับ
- คะแนนความเสี่ยง (`Risk Score`) และระดับความรุนแรง (`Severity`)
- ผลการวิเคราะห์จาก AI (`AI Analysis`)
- ข้อมูล `MITRE ATT&CK Mapping`
- ผลการตรวจสอบและหมายเหตุของผู้ใช้งาน (`Analyst Review`)

### ขั้นตอนที่ 6: สิ้นสุดการใช้งาน (End Session)
ระบบไม่ต้องการการเข้าสู่ระบบหรือสมัครสมาชิก และจะเก็บข้อมูลเฉพาะในช่วงการใช้งานปัจจุบัน (**Temporary Session**)
- เมื่อเสร็จสิ้น ผู้ใช้งานสามารถกดปุ่ม **End Session (สิ้นสุด Session)** บนแถบด้านบนหรือในหน้า **`Report`**
- ระบบจะลบข้อมูลชั่วคราวที่เกี่ยวข้องกับการวิเคราะห์ทั้งหมด รวมถึง **Session Audit Log** ทันที โดยผู้ใช้งานยังคงเก็บไฟล์รายงาน PDF / CSV ที่ดาวน์โหลดไว้ได้

## 2. หน้าหลักของระบบ (4 หน้าหลัก)

1. **`Dashboard & Upload`**
   - แสดงภาพรวมข้อมูล Alert ใน Session ปัจจุบัน (จำนวน Alert ทั้งหมด, แยกตามระดับความเสี่ยง Critical / High / Medium / Low, กราฟสรุปผล) และส่วนอัปโหลดไฟล์ JSON / CSV หรือกรอกข้อมูลด้วยตนเอง
2. **`Analysis Workspace`**
   - เลือก Alert จากรายการใน Session, กดปุ่ม **Analyze**, และดูรายละเอียดเหตุการณ์ + คะแนนความเสี่ยง (`Risk Score`) + ผลวิเคราะห์ AI (`AI Analysis`) + ข้อมูล `MITRE ATT&CK` ในหน้าเดียว
3. **`Analyst Review & Audit`**
   - ตรวจสอบผลวิเคราะห์ของ AI, เพิ่มหมายเหตุ/รูปภาพหลักฐาน, ยืนยันหรือแก้ไขผล และดูประวัติการใช้งานใน Session ปัจจุบัน (**Session Audit Log**)
4. **`Report`**
   - แสดงตัวอย่างรายงาน ดาวน์โหลดรายงานในรูปแบบ **PDF** หรือ **CSV** และกดปุ่ม **End Session** เพื่อสิ้นสุดการใช้งานและลบข้อมูลชั่วคราว

## 3. วิธีการรันระบบ (Quick Start)

1. **เปิดเซิร์ฟเวอร์ Backend (พอร์ต 8080):**
   ```powershell
   cd d:\fightikeeee\backend
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8080
   ```
2. **เปิดเซิร์ฟเวอร์ Frontend (พอร์ต 3000):**
   ```powershell
   cd d:\fightikeeee\frontend
   npm run dev
   ```
3. **เปิดเบราว์เซอร์ไปที่:** `http://localhost:3000` หรือ `http://localhost:8080`
